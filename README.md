# Features
- User Authentication: Secure login and registration for customers and bank administrators.
- Account Management: Create, view, and close savings or current accounts.
- Core Transactions: Deposit, withdraw, and transfer funds between accounts with real-time balance updates.
- Transaction History: Generate and view a detailed log of past transactions.
- Admin Dashboard: Special access for administrators to manage user accounts and view total bank assets.

# Tech Stack
- Language: Python
- GUI: CustomTkinter
- Database: MySQL
